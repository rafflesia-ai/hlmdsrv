## hlmdsrv completion

Print shell completion scripts

```
hlmdsrv completion SHELL [flags]
```

### Options

```
      --force        overwrite an existing completion file
  -h, --help         help for completion
  -o, --out string   write completion script to this path instead of stdout
```

### Options inherited from parent commands

```
      --profile string     load defaults from a named config profile or MDSRV_PROFILE
      --timeout duration   overall command timeout, for example 5m; profile timeout is used when unset
```

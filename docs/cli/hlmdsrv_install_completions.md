## hlmdsrv install completions

Install shell completions

```
hlmdsrv install completions [flags]
```

### Options

```
      --force          overwrite existing completion file
  -h, --help           help for completions
  -o, --out string     completion output path
      --shell string   shell: zsh, bash, fish (default "zsh")
```

### Options inherited from parent commands

```
      --profile string     load defaults from a named config profile or MDSRV_PROFILE
      --timeout duration   overall command timeout, for example 5m; profile timeout is used when unset
```

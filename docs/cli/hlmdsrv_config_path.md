## hlmdsrv config path

Print the active config file path

```
hlmdsrv config path [flags]
```

### Options

```
      --config string   config file path; defaults to $XDG_CONFIG_HOME/hlmdsrv/config.yaml
  -h, --help            help for path
      --json            write machine-readable output
```
